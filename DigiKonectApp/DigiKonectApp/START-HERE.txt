DIGIKONECT APP - QUICK START

1. Install .NET 8 SDK and Node.js.
2. Open backend folder in terminal:
   dotnet restore
   dotnet run --urls http://localhost:5000
3. Open a second terminal in frontend folder:
   npm install
   npm run dev
4. Open http://localhost:5173
